# ConvertPolo – QA Assignment

## Overview

A practical QA assignment completed as part of the ConvertPolo hiring process.

The assignment involved testing three e-commerce websites and documenting test scenarios, defects, and API testing results.

### Websites Tested

- ConvertPolo
- iTokri
- AnotherSole

## Testing Scope

### Manual Testing

- Functional testing
- UI testing
- E-commerce workflow testing
- Test case design
- Bug identification and reporting
- Responsive/mobile testing
- Cross-browser/UI validation

### API Testing

- Shopify storefront API testing using Postman
- Product API validation
- Invalid product handle validation
- Collection API validation
- Cart add/update/clear operations
- Cart state validation
- Inventory/availability validation
- Variant validation
- Cart total and UI/API synchronization checks

API testing was performed on the iTokri and AnotherSole Shopify stores.

## Deliverables

| Deliverable              | Description                                              |
| ------------------------ | -------------------------------------------------------- |
| Assignment PDF           | Original assignment requirements                         |
| Test Cases & Bug Reports | Test scenarios, execution results and identified defects |
| Postman Collection       | API testing collection for iTokri and AnotherSole        |
| Test Evidence            | Screenshots/evidence supporting identified issues        |

## API Testing

The Postman collection contains API_001–API_010 test scenarios for both iTokri and AnotherSole.

The collection includes validations for HTTP status codes, response structure, response time, product/variant data, cart operations and API/UI consistency.

The collection uses Postman environment variables for the two storefronts.

### API Testing Scope

The API portion of the assignment was executed against iTokri
and AnotherSole, which were the applicable Shopify storefronts.

ConvertPolo's website did not provide the required e-commerce
storefront/API functionality for this module.

## Key Outcome

The assignment provided hands-on experience with testing real e-commerce storefronts, designing test scenarios, identifying UI/functional issues, documenting defects, and performing API validation using Postman.
